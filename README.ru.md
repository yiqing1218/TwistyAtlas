# Twisty Atlas — атлас формул кубика

Библиотека формул для кубиков разных типов + **настоящий трёхмерный** плеер движений + **таймер в стиле csTimer**.
Формулы, подсветка шагов и трёхмерная картина строго синхронизированы; встроено **37 наборов формул (2433 кейса / 13667 формул)**;
данные хранятся локально, доступен офлайн-режим. Десктопная и Android-версии имеют независимые варианты взаимодействия (это не один и тот же масштабируемый экран).

Это не картинка и не видео: куб / тетраэдр / додекаэдр отрисовываются в реальном времени через WebGL, каждый поворот слоя вычисляется моделью состояний
`cubing.js`, а тесты проверяют корректность по состоянию движка, а не по скриншотам.

## Возможности

### Трёхмерный плеер
- **Настоящая трёхмерная анимация**: 9 типов — 3×3, 2–7×7, пирамида (Pyraminx), скьюб (Skewb), мегаминкс (Megaminx) — являются настоящим 3D;
  Square-1 отображается в 2D (ограничение движка, честно указано).
- **Пошаговое воспроизведение формулы**: счётчик 0 / N шагов, перетаскиваемый индикатор прогресса, предыдущий / следующий шаг, переход к началу / концу, скорость 0.5×–2×.
  Клик по k-му шагу всегда останавливает плеер на кадре завершения k-го шага (позиционирование идёт по временной шкале движка, а не по таймеру).
- **Три исходных состояния**: начать с решённого состояния / использовать обратную формулу как исходное / пользовательский setup (для случаев OLL, PLL, F2L и др.).
- **Выбираемая демонстрационная нижняя грань**: жёлтый (по умолчанию) / белый / синий / зелёный / красный / оранжевый. Дело не в том, чтобы «повернуть камеру»,
  а в сопряжении формулы вместе с исходным состоянием `R·A·R⁻¹`: конечное состояние остаётся решённым, меняется только общая ориентация;
  выбор сохраняется, а при переключении текущая формула сразу перезагружается.
- **Камера и ракурс**: вращение перетаскиванием, масштабирование колёсиком, сброс в один клик. **Движение камеры не меняет состояние кубика** (есть отдельный тест-кейс).

| Категория | Содержание |
|---|---|
| 3×3 · основная линия CFOP | OLL 57, PLL 21, 2-Look OLL 10, 2-Look PLL 6, F2L 41 |
| 3×3 · продвинутая система | COLL 40, WV 26, ZBLL/1LLL 472, **VLS 189**, ZBLS 291, OLLCP 342, CLS 97, SBLS 65, SV 27, CMLL 42, ELL 25, Advanced F2L 54, Pseudo F2L 33 |
| 2×2 | CLL 42, EG-1 40, EG-2 40, Ortega OLL 7, Ortega PBL 9 |
| 4×4 / 5×5 | 4×4 OLL Parity 9, 4×4 PLL Parity 52, 5×5 L2E 31 |
| Пирамида / Мегаминкс / SQ-1 | Пирамида L4E 49; Мегаминкс CO/CP/EO/EP/PLL 16/15/3/5/151; SQ-1 CO/CP/EO/EP/Parity 7/8/7/99/5 |

Каждая формула прошла структурную проверку с помощью настоящего KPuzzle (9357 формул прошли полную проверку состояний, 4310 — проверку синтаксиса и разбираемости),
панель деталей показывает источник и уровень проверки; 399 отклонённых формул записаны в `data/verified/rejected.json`.
Подробности — в [`docs/DATA_SOURCES.md`](docs/DATA_SOURCES.md).

### Таймер (в стиле csTimer)
- Верхняя строка со скрамблом (настоящее случайное состояние по WCA) + кнопка «другой» (`N`); текст скрамбла на телефоне полностью переносится по строкам, без обрезки.
- Удерживайте пробел (или область с крупными цифрами) ≥ 300 мс — индикатор станет зелёным → отпустите для старта; нажмите ещё раз для остановки.
- Инспекция WCA: старт в течение 15 с, 15–17 с — штраф `+2`, более 17 с — `DNF` (можно включить / выключить).
- Статистика: текущее / лучшее / худшее / среднее / mo3 / ao5 / ao12 / **ao50 / ao100** / лучшее ao5 / ao12 / ao50,
  среднее без крайних значений, корректные правила DNF.
- **Построчное редактирование результатов**: одиночный клик по `+2` / `DNF` переключает штраф, клик удаляет запись; клавиша `Delete` удаляет последнюю запись; очистка сессии.
- **Экспорт**: CSV (открывается прямо в Excel, содержит штрафы, скрамблы, метки времени) / JSON (полный набор полей) / обычный текст (выровненная таблица).
- Правая колонка: настоящий `TwistyPlayer` показывает, «как выглядит этот скрамбл» (не картинка).
- Семисегментный дисплей выполнен чистыми SVG-полигонами (скошенные штрихи + `skewX(-6)`), без зависимости от шрифтов; ширина адаптивная,
  при длинных числах вроде `1:23.456` показания автоматически уменьшаются и не обрезаются на узких экранах.

### Управление библиотекой формул
- Поиск (по названию / формуле / тегам), фильтрация по категориям и тегам, избранное, сортировка, создание / редактирование / копирование / удаление / отмена удаления.
- Импорт и экспорт в двух форматах — JSON и CSV; перед импортом — предпросмотр с пометкой дубликатов; импорт как единая транзакция, при ошибке — полный откат.
- На десктопе — три колонки; на телефоне «список + детали» больше не рядом: по клику на запись открывается отдельная страница формулы (с плеером).

### Два интерфейса: десктоп / телефон
| | Десктоп (> 760 px) | Телефон (≤ 760 px) |
|---|---|---|
| Навигация | Верхняя горизонтальная навигация (включая трёхколоночный вид «Рабочий стол») | **4 нижние вкладки**: таймер / наборы формул / библиотека формул / настройки (досягаются большим пальцем, не перекрывают зону системных жестов) |
| Раскладка | Три колонки рядом | Одна колонка, крупные области (плеер / большой таймер) фиксированной высоты, список прокручивается внутри контейнера, **вся страница не прокручивается по вертикали** |
| Точка входа | Рабочий стол `#/` | Автоматический переход на `#/sets` (рабочий стол — трёхколоночный объединённый вид только для десктопа) |
| Плотность информации | Все поля | Убраны повторяющиеся заголовки, счётчики и длинные пояснения, оставлены ключевые действия |

### Шестиязычный интерфейс
- Интерфейс поддерживает 简体中文 / English / 日本語 / Русский / Español / Português (BR): переключение «Настройки → Язык» действует немедленно и сохраняется; режим «Следовать за системой» определяется по предпочтительному языку браузера.
- Нижние слои (`domain` / `application` / `infrastructure`) не содержат текста интерфейса; переводы сосредоточены в слое представления — `src/presentation/i18n/`. Ключи словаря выводятся из базового языка: отсутствие или лишний ключ вызывает ошибку типов, а юнит-тест проверяет, что наборы ключей и плейсхолдеры интерполяции совпадают во всех шести языках.
- README также представлен на шести языках — переключение в одну строку вверху страницы.

### Горячие клавиши (плеер)
| Клавиша | Действие |
|---|---|
| `Space` | Воспроизведение / пауза (на странице таймера — запуск / остановка отсчёта) |
| `←` / `→` | Предыдущий / следующий шаг |
| `Home` / `End` | Переход к началу / концу |
| `Delete` | На странице таймера удаляет последний результат |
| `Esc` | Закрыть диалог / отменить отсчёт |

## Архитектура

Слои (`domain / application / infrastructure / presentation / data`), направление зависимостей статически контролируется
`scripts/check-arch.mjs` (67 файлов), `cubing/*` допускается только в `infrastructure/cubing`:

```
src/
  domain/                  # чистая логика, без зависимостей от фреймворков
    model/                 #   формулы, кубики, результаты, настройки, демонстрационная ориентация (orientation)
    timer/                 #   конечный автомат таймера (чистые функции), статистика, форматирование
  application/
    sets/                  #   загрузка и классификация встроенных наборов формул
    timer/                 #   экспорт результатов (CSV / JSON / текст, чистые функции)
  infrastructure/
    cubing/                # единственное место, работающее с cubing.js (включая adapters/)
    persistence/           #   Dexie: формулы, результаты, настройки
  presentation/            # компоненты Vue / представления / Pinia store / маршрутизация / composables / i18n
  data/algsets.json        # наборы формул, сгенерированные при сборке (отдельный chunk, не загружается на первом экране)
e2e/                       # Playwright (десктоп + мобильный)
scripts/                   # конвейер данных, проверка архитектуры, сборка, верификация и скриншоты
docs/                      # архитектура, данные, упаковка, доказательства приёмки
```

Подробности — в [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

## Данные и конфиденциальность

- Все данные хранятся в IndexedDB браузера (имя базы `TwistyAtlasDB`), без загрузки на сервер, без аккаунтов и без бэкенда.
- При очистке данных сайта формулы и результаты потеряются — рекомендуется регулярно делать резервную копию через «Экспорт JSON».
- Импорт принимает только поля из белого списка, HTML отображается как обычный текст (есть отдельный тест, подтверждающий, что скрипты не выполняются).

## Известные ограничения

1. **Square-1 отображается только в 2D**: у `cubing@0.66.1` параметр `visualizationStrategy` для Square-1 в реальном тесте равен `2D`, реальной трёхмерной модели деформации нет. В области воспроизведения показывается значок «2D-рендеринг», который не выдаёт его за 3D.
2. **Воспроизводимых кубиков ровно 10**: движок содержит 21 тип, но те, что не прошли построчную приёмку по состояниям, не появляются в списке выбора.
3. **Android-пакет не проверен на реальном устройстве**: компиляция и проверка структуры пакета прошли, но на машине нет AVD / устройства, поэтому установка и запуск не проверялись.
4. **Десктопная версия не подписана и не имеет собственного значка**: при первом запуске может появиться предупреждение «неизвестный издатель».
5. **Автообновление PWA может прервать редактирование**: `registerType: 'autoUpdate'`, не реализована «отложенная установка обновления при несохранённых изменениях».
6. **Нет облачной синхронизации**: для переноса между устройствами используйте экспорт / импорт.
7. **На телефоне нет полноценной раскладки для альбомной ориентации**: в альбомном режиме приложение работает, но высота плеера вычисляется через `vh`, поэтому видимая область невелика.

## Требования к браузеру

WebGL2 + IndexedDB + ES2022. Проверено в Chromium (встроенный в Playwright канал `chromium`, программный рендеринг SwiftShader) и Electron 45.
