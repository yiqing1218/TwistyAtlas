# Twisty Atlas ルービックキューブ公式図譜

複数タイプのキューブに対応する公式ライブラリ + **真の 3D** 動作プレイヤー + **csTimer スタイルのタイマー**。
公式、ステップのハイライト、3D 映像は厳密に同期します。**37 セットの公式集（2433 ケース / 13667 本の公式）**を内蔵。
データはローカルに保存され、オフラインでも使用できます。デスクトップ版と Android 版はそれぞれ独立したインタラクション形態を持ちます（同じページの拡大縮小ではありません）。

単なる効果図でも動画でもありません：立方体／四面体／十二面体は WebGL でリアルタイムに描画され、各層の回転は
`cubing.js` の状態モデルによって計算されます。テストではスクリーンショットではなくエンジンの状態によって正誤を検証します。

## 機能

### 3D プレイヤー
- **真の 3D 再生**：3x3、2x2〜7x7、ピラミント、スキューブ、メガミンクス、計 9 種類が真の 3D です；
  Square-1 は 2D 描画です（エンジンの制限であり、ありのままに明記しています）。
- **公式のステップ再生**：0 / N ステップ表示、ドラッグ可能なプログレスバー、前のステップ／次のステップ、先頭／末尾へのジャンプ、0.5×〜2× の速度変更。
  第 k ステップをクリックすると必ず第 k ステップ終了時の画面で停止します（位置指定はタイマーではなくエンジンのタイムラインに基づきます）。
- **3 種類の初期状態**：復元状態から開始 / 逆公式を初期状態とする / カスタム setup（OLL、PLL、F2L などのケース用）。
- **選択可能なデモ底面**：黄（デフォルト）/ 白 / 青 / 緑 / 赤 / 橙。方法は「カメラを回す」ではなく、
  公式と初期状態を一緒に共役 `R·A·R⁻¹` にかけます。終状態は復元状態のままで、全体の向きだけが異なります；
  選択内容は永続化され、切り替えると現在の公式が即座に再読み込みされます。
- **カメラと視点**：ドラッグで回転、ホイールでズーム、ワンクリックでリセット。**カメラの移動はキューブの状態を変えません**（専用のテストケースがあります）。

### 内蔵公式集（37 セット / 2433 ケース / 13667 本）
| 分類 | 内容 |
|---|---|
| 3x3 · CFOP 本線 | OLL 57、PLL 21、2-Look OLL 10、2-Look PLL 6、F2L 41 |
| 3x3 · 応用体系 | COLL 40、WV 26、ZBLL/1LLL 472、**VLS 189**、ZBLS 291、OLLCP 342、CLS 97、SBLS 65、SV 27、CMLL 42、ELL 25、Advanced F2L 54、Pseudo F2L 33 |
| 2x2 | CLL 42、EG-1 40、EG-2 40、Ortega OLL 7、Ortega PBL 9 |
| 4x4 / 5x5 | 4×4 OLL Parity 9、4×4 PLL Parity 52、5×5 L2E 31 |
| ピラミント / メガミンクス / SQ-1 | ピラミント L4E 49；メガミンクス CO/CP/EO/EP/PLL 16/15/3/5/151；SQ-1 CO/CP/EO/EP/Parity 7/8/7/99/5 |

すべての公式は実際の KPuzzle による構造検証を経ています（9357 本が完全な状態検証を通過、4310 本が構文＋解析可能検証を通過）。
詳細パネルには出典と検証レベルが表示されます。除外された 399 本は `data/verified/rejected.json` に記録されています。
詳細は [`docs/DATA_SOURCES.md`](docs/DATA_SOURCES.md) を参照してください。

### タイマー（csTimer スタイル）
- 上部のスクランブルバー（実際の WCA ランダム状態）＋別のものに変更（`N`）；スクランブル文字はスマートフォンでも完全に折り返して表示され、切り詰められません。
- スペースキー（または大きな数字エリア）を ≥ 300 ms 押し続けると緑色に変化 → 離すと開始。もう一度押すと停止します。
- WCA 観察：15 s 以内に開始、15〜17 s で `+2` 判定、17 s 超で `DNF` 判定（オン／オフ可能）。
- 統計：現在 / ベスト / ワースト / 平均 / mo3 / ao5 / ao12 / **ao50 / ao100** / ベスト ao5 / ao12 / ao50。
  最大値と最小値を除いた平均、DNF ルールは正しく処理されます。
- **成績を個別に編集可能**：`+2` / `DNF` をクリックしてペナルティを切り替え、クリックで 1 件削除。`Delete` キーで最後の 1 件を削除。セッションをクリア。
- **エクスポート**：CSV（Excel で直接開けます。ペナルティ、スクランブル、タイムスタンプを含む）/ JSON（全フィールド）/ プレーンテキスト（表を整形）。
- 右カラム：実際の `TwistyPlayer` で「このスクランブルはどのような形か」をプレビューします（画像ではありません）。
- 7 セグメント数码表示は純粋な SVG ポリゴン（斜めにカットされたストローク + `skewX(-6)`）で、フォントに依存しません。幅は自動調整され、
  `1:23.456` のような長い数字の計時時には自動的に縮小し、狭い画面でも切り詰められません。

### 公式ライブラリ管理
- 検索（タイトル／公式／タグ）、カテゴリとタグによる絞り込み、お気に入り、並べ替え、新規作成／編集／複製／削除／削除の取り消し。
- JSON と CSV の 2 形式でインポート／エクスポート。インポート前にプレビューして重複項目を表示。全体がトランザクション処理され、失敗時はすべてロールバックされます。
- デスクトップは 3 カラム。スマートフォンでは「一覧 ＋ 詳細」を並べて表示せず、1 件をタップするとそのまま詳細ページ（プレイヤー付き）に移動します。

### デスクトップ / スマートフォンの 2 種類のインターフェース
| | デスクトップ（> 760 px） | スマートフォン（≤ 760 px） |
|---|---|---|
| ナビゲーション | 上部の横型ナビゲーション（「ワークベンチ」3 カラムビューを含む） | **下部 4 つのタブ**：タイマー / 公式集 / 公式ライブラリ / 設定（親指で届き、フルスクリーンのジェスチャー領域を避けます） |
| レイアウト | 3 カラム並列 | 1 カラム。大きな領域（プレイヤー／大型タイマー）は高さ固定、一覧はコンテナ内でスクロールし、**ページ全体は上下にスクロールしません** |
| 入口 | ワークベンチ `#/` | 自動的に `#/sets` へ（ワークベンチはデスクトップ専用の 3 カラム統合ビューです） |
| 情報密度 | 全フィールド | 重複するタイトル、重複するカウント、長い説明を除去し、主要な操作を保持 |

### 6 言語インターフェース
- インターフェースは 簡体字中国語 / English / 日本語 / Русский / Español / Português (BR) の 6 言語に対応し、「設定 → 言語」で即時に切り替えられ、選択は永続化されます。「システムに従う」はブラウザの優先言語に従って解決されます。
- 下位層（`domain` / `application` / `infrastructure`）には画面上の文言を含みません。翻訳は表現層の `src/presentation/i18n/` に集約されています。辞書キーは基準言語から導出され、キーの不足や過剰は型エラーとなります。さらに単体テストで 6 言語のキー集合と補間プレースホルダーの一致を検証します。
- README 自体も 6 言語で提供され、上部の 1 行で相互に切り替えられます。

## アーキテクチャ

階層分割（`domain / application / infrastructure / presentation / data`）。依存方向は
`scripts/check-arch.mjs` によって静的に守られています（67 ファイル）。`cubing/*` は `infrastructure/cubing` にのみ出現を許可されています：

```
src/
  domain/                  # 純粋なロジック、フレームワーク依存ゼロ
    model/                 #   公式、キューブ、成績、設定、デモの向き(orientation)
    timer/                 #   タイマーの状態マシン（純粋関数）、統計、フォーマット
  application/
    sets/                  #   内蔵公式集の読み込みと分類
    timer/                 #   成績のエクスポート（CSV / JSON / テキスト、純粋関数）
  infrastructure/
    cubing/                #   cubing.js と直接やり取りする唯一の場所（adapters/ を含む）
    persistence/           #   Dexie：公式、成績、設定
  presentation/            # Vue コンポーネント / ビュー / Pinia store / ルーティング / composables / i18n
  data/algsets.json        # ビルド時に生成される公式集（独立チャンク、初回画面では読み込まない）
e2e/                       # Playwright（デスクトップ + モバイル）
scripts/                   # データパイプライン、アーキテクチャチェック、パッケージング、検証、スクリーンショット
docs/                      # アーキテクチャ、データ、パッケージング、受け入れ証拠
```

詳細は [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) を参照してください。

## データとプライバシー

- すべてのデータはブラウザの IndexedDB（データベース名 `TwistyAtlasDB`）に保存され、**アップロードなし、アカウントなし、バックエンドなし**です。
- サイトデータを消去すると公式／成績が失われるため、定期的な「JSON エクスポート」によるバックアップをおすすめします。
- インポートはホワイトリストのフィールドのみを受け付け、HTML はプレーンテキストとして描画されます（スクリプトが実行されないことを検証する専用のテストケースがあります）。

## 既知の制限

1. **Square-1 は 2D 描画のみ**：`cubing@0.66.1` における Square-1 の `visualizationStrategy` の実測値は `2D` であり、
   真の 3D 変形モデルはありません。再生エリアには「2D 描画」バッジが表示され、**3D を装いません**。
2. **再生可能なキューブは 10 種類に限定**：エンジンは 21 種類を内蔵していますが、状態ごとの受け入れ検証を行っていないものはセレクターに表示されません。
3. **Android パッケージは実機未検証**：コンパイル成功 ＋ パッケージ構造検証は通過していますが、ローカルに AVD／デバイスがなく、インストールと実行の検証は行っていません。
4. **デスクトップ版は未署名、アイコン未変更**：初回実行時に「不明な発行者」と表示される可能性があります。
5. **PWA の自動更新が編集を中断する可能性があります**：`registerType: 'autoUpdate'` であり、「未保存の変更がある場合は更新を遅延する」は未実装です。
6. **クラウド同期は行いません**：デバイス間ではエクスポート／インポートをご利用ください。
7. **スマートフォン版は横向きの演奏グレードなレイアウトに非対応**：横向きでも使用できますが、プレイヤーの高さが `vh` で計算されるため、横向きでは表示領域がやや小さくなります。
