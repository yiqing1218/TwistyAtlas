# Twisty Atlas v1.3.0

> 说明：本文对应 `v1.3.0` tag 与当时生成的二进制附件。tag 之后的六语界面增补
> （zh-CN / en / ja / ru / es / pt-BR）属于同版本后续提交，**未重新打 tag、未替换 Release 附件**；
> 详见 [`../ACCEPTANCE_REPORT.md`](../ACCEPTANCE_REPORT.md) 末尾的「六语界面增补验收」。

多类型魔方的公式库 + 真实三维动作播放器 + csTimer 风格计时器。
公式、步骤高亮与三维画面严格同步；立方体/四面体/十二面体由 WebGL 实时渲染。
数据全部存在本机，离线可用，无账号、无后端。

## 下载

| 平台 | 文件 | 说明 |
|---|---|---|
| Windows x64 | `TwistyAtlas-1.3.0-windows-x64.zip` | 解压后双击 `TwistyAtlas.exe`，免安装、免管理员权限 |
| Android | `TwistyAtlas-1.3.0-android-debug.apk` | debug 签名，安装时需允许"未知来源" |

**Windows**：解压整个文件夹再运行，不要只把 exe 拖出来——`resources/`、`locales/`、各 `.dll`
必须和 exe 放在同一目录。首次运行可能提示"未知发布者"，因为未做代码签名。

**Android**：`minSdk 23`（Android 6.0）及以上。debug 签名仅供试用，不是可上架的正式包。

## 本版内容

### 公式集：37 套 / 2433 案例 / 13667 条公式

- 三阶：CFOP（F2L / OLL / PLL 全量）、VLS 189、ZBLS 291、OLLCP 342、CLS 97、SBLS 65、
  SV 27、CMLL 42、ELL 25、Advanced F2L 54、Pseudo F2L 33
- 二阶：EG-1 40、EG-2 40、Ortega OLL 7、Ortega PBL 9
- 金字塔 L4E 49；五魔方 CO/CP/EO/EP/PLL；SQ-1 CO/CP/EO/EP/Parity
- 每条公式标注校验级别：`structural`（用引擎跑通状态闭合）或 `parsed`（仅语法校验），
  不冒充已验证。被拒的 399 条逐条留档在 `data/verified/rejected.json`

### 计时器

- 导出 **CSV / JSON / 纯文本**
- 单条成绩 **+2 / DNF** 切换、单条删除、`Delete` 键删最后一条
- 统计：best / worst / mean / mo3 / ao5 / ao12 / ao50 / ao100 与各自最佳
- WCA 观察 15 秒（超时 +2、再超 DNF），按住 300ms 变绿出发

### 演示底面

黄（默认）/ 白 / 蓝 / 绿 / 红 / 橙。实现是共轭变换 `A' = R·A·R⁻¹`，不是转镜头，
所以播放终态仍是复原态——这条被写成自动化断言。

### 手机端独立界面

不是桌面布局的缩放版：导航移到底部（让开全面屏手势区）、整页锁死不滚动
（只有列表区域内部滚动）、去掉重复标题与冗余统计。

## 已知限制

1. **Square-1 只有二维渲染**：`cubing.js` 对 Square-1 没有真实三维形变模型，界面如实标注。
2. **可播放魔方限定 10 种**：引擎自带 21 种，未做逐状态验收的不出现在选择器里。
3. **安卓包未上真机**：编译与包结构校验通过，但无设备可测，未做安装运行验证。
4. **桌面端未签名、未换图标**：首次运行可能提示"未知发布者"。
5. **部分进阶集合只到语法校验**：ZBLS / OLLCP / Advanced F2L 中有一批 AUF 超出
   `U / U2 / U'` 的搜索范围，页面标注为"仅语法校验"，没有冒充已验证。
6. **不做云同步**：跨设备请用导出 / 导入 JSON。
